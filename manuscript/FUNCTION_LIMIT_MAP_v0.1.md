## Limit Map

| Limit ID | Failure/limit condition | Required response |
| --- | --- | --- |
| L-01 | No native second-order stable restoring factor supports canonical chi | Refuse that scalar; use generator/modal description |
| L-02 | Barrier-top unstable curvature is being substituted for stable-well natural frequency | Refuse critical-damping interpretation; use native barrier theory |
| L-03 | Spectral width contains unresolved dephasing/inhomogeneous/instrumental contributions | Lower claim ceiling or separate/bound contributions |
| L-04 | Two friction/damping estimators have not been shown equivalent | Keep them separate; no pooled coordinate |
| L-05 | Bath memory is comparable to local dynamical timescale | Refuse Markovian reduction or use non-Markovian model |
| L-06 | Finite-precision near-degeneracy lacks continuation/structural proof | Do not claim structurally certified EP |
| L-07 | Embedded system cannot be reduced without losing material mode/coupling information | Retain modal/conglomerate representation; no scalar averaging shortcut |
| L-08 | Atlas row mismatches system, phase, temperature, medium, or reaction event | Refuse pairing or mark provisional |
| L-09 | Multiple rows share the same underlying experiment/model/source family | Treat dependence explicitly; do not count as independent replications |
| L-10 | Representative was selected after seeing favorable residual/agreement | Discovery/diagnostic only; not confirmatory summary |
| L-11 | Native comparator is stronger or equivalent on the frozen predictive task | Classify as FAILS or EQUIVALENT; do not claim added value |
| L-12 | Active computation is process-complete but scientific gates are not closed | Scientific status remains pending/HOLD |
| L-13 | System diversity is insufficient for a general inheritance law | Restrict claim to tested systems/families |
| L-14 | Method failure is observed | Do not relabel as physical phase transition without independent test |
